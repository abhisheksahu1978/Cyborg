# CYBERNEX — Futuristic Cyborg Landing Page

A responsive landing page concept exploring robotics, artificial intelligence, cybernetic vision, and neural networks.

## Features
- Futuristic dark UI with cyan and purple accents
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Animated visual elements and scrolling ticker
- Technology cards, vision section, and contact CTA
- Semantic HTML and reduced-motion support

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Internet is required for Google Fonts and the remote Unsplash images.

## Customization
Replace the sample images and `hello@cybernex.example` with your preferred assets and contact details before publishing.

## Note
CYBERNEX is a student concept project. It is not an official IIT Bombay or Techfest website.
